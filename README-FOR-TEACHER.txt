Gemora - Jewellery Management System
====================================
Run (no IntelliJ needed):  Java 11 or newer must be installed.
  1. Double-click  Gemora.exe  (or start-gemora.bat).  A black window opens = the server.
  2. The browser opens http://localhost:8080/   (if not, type this address)
  3. Password: admin123
  4. To stop: close the black window.

Run from IntelliJ:  File -> Open this folder -> open src/com/jewellery/Main.java -> Run.

Folders: src (Java source code), webapp (JSP pages, css, js, pictures), lib (server jars),
data (text files where items, customers, sales, orders and carts are saved).
